# 03 · 人格陪伴模型的诊断：不依赖 LLM 判官的评估

日期 2026-11-16 · 预设 `mbti-1ep` / `mbti-4ep` / `mbti-v8-1ep` · 单个随机种子 · 经独立核查

## 背景
一个 16 型人格陪伴对话模型（Qwen2.5-7B-Instruct + LoRA）在人工盲审中 160 条回答里有 123 条跑题，而 LLM 判官的分数看不出问题。这里要回答两件事：微调到底有没有学到"按人格说话"？跑题从哪里来？

数据有两版，都由教师模型生成，**不随仓库发布**：
- v6：4,214 条，提示格式是 `[以 INTJ 人格的身份回复] 好友说：……`。
- v8：2,866 条，提示格式是"整张人设卡 + 好友说：……"。

## 方法（都不需要 LLM 判官，可完全复现）
| 指标 | 怎么算 | 回答什么 |
|---|---|---|
| 整组留出验证 | 去掉人格标签、"好友说/朋友说"前缀和括号里的变体说明，得到**核心问题**；整组留出 10% 的核心问题，训练中从不出现。另按"条"随机切 8% 当"见过的问题"验证集 | 学到的是"怎么回答"，还是记住了具体题目 |
| 型贴近度 | 同一条参考回答分别放在 16 种人格提示后面，看哪个让模型给出的概率最高（随机 6.25%） | 模型是否贴近教师按型写的风格（**不等于人觉得像**） |
| 背诵率 | 生成回答里的 8 字片段，有多少能在训练集回答里原样找到 | 是不是在照抄 |
| 切题度 | 关掉所有改动，用原始基座给生成的回答打分：配自己的问题 − 配别的问题，平均每 token 对数概率 | 回答和问题对不对得上 |

第一次分组时只按开场原句分，24 组里有 9 组是训练题的变体（例如"深夜有点 emo，想找人说说话（深夜独处型……）"），也就是发生了泄漏。改成按核心问题分组后，留出问题与训练问题的最高字符二元组相似度是 0.38：话题相近，措辞不同。所以本文说的"没见过的问题"准确地说是**措辞没见过**。

## 结果

**数据本身**
- v6 的 4,214 条只有 **149 个核心问题**，最大的一个出现 134 次。原项目按"条"随机切验证集，复刻后 287/287 条验证样本的问题训练时都见过，val loss 测不出泛化。
- v8 有 551 个核心问题，但教师口头禅"先别急"出现在 36% 的回答里。

**0.6B（Qwen3-0.6B-Base），v6 数据**
| | 1.07 轮 | 4.26 轮 |
|---|---|---|
| 型贴近度 top-1（48 条） | **58%**（95% 区间约 44–71%） | 69% |
| 对照：基座 + 人格标签 / 基座 + 人设卡 | 15% / 21% | 同左 |
| 没见过问题的损失 | 4.13 → 3.17 | 第 1.86 轮最低（3.12），终点回升到 3.24 |
| 中文通用文本损失变化 | −0.5% | **+4.8%** |
| 与基座的 KL | 0.09 | 0.23 |
| 背诵率 / 答完会停 | 12% / 12 of 12 | 8% / 12 of 12 |

结论：
- 微调学到的人格口吻比只给一张人设卡贴近得多。
- 训到 4 轮出现轻度过拟合，遗忘变大约 10 倍。
- 在这个设置下，4 轮**没有**出现可检测的背诵或跑题；但生成只有 12 条，检出力低。

**同一份 v8 数据：0.6B vs 7B**
| | 0.6B，TinyLab 配方，1.11 轮 | 7B，mlx 配方，第 400 步 / 1 轮 |
|---|---|---|
| 复读 | 0/12 | 贪心解码 6/12 |
| 切题度（7B 基座 + 卡 = 0.88） | — | 0.33 / 0.20 |
| 人设卡指令词（"接住""顶嘴"）出现 | 3/12 | 4–5/12 |
| 型贴近度（7B 用 v8 自己的验证集作参考） | 17% → 60% | 21% → 15% / 8% |

7B 的评估用的是温度 0.7、top-p 0.9、重复惩罚 1.1。核查排除了格式假象：训练和评估用同一个 chat 模板、同一份 adapter 配置、同一个 8 位基座，对数概率的位置对齐也正确。

**结论：** 同一份数据，小模型正常，7B 退化，所以问题不在数据本身，而在 7B 这一侧（训练配方或基座）。原先"背题导致跑题"的假设，没有被 0.6B 实验支持。

## 局限
- 单个种子；判型 48 条、生成 12 条，只能看方向。
- 型贴近度的参考回答来自同一个教师，本质上是"贴近教师风格"的测量，上线前仍需人工盲审。
- 0.6B Base 和 7B Instruct 的条件不同，不能据此断言原项目的跑题与过拟合无关。

7B 退化的原因见 [04 · 7B 单变量实验](04-7b-single-variable.md)。
