# 01 · 从零训练小 GPT：7 组对照实验

日期 2026-11-15 · 设备 Apple M 系列（MPS）· 单个随机种子 · 数字均来自 `runs/<预设>/eval.jsonl`，经独立核查

## 设置
- 语料：`pycode`（Python 标准库源码约 4MB）、`pycode-large`（标准库 + site-packages 约 40MB）、模加法（p = 97）。
- 模型：pre-LN GPT，输入嵌入与输出层共享权重；0.9M（tiny）与 2.9M（small）两档。
- 评估：每次评估用同一组固定的 batch（种子 12345）。第一版是每次随机抽 batch，相邻两次评估相差 0.17，比实验组之间的差距还大，因此改为固定。
- 不同分词器之间用**每字节比特（bpb）**比较：bpb = 验证 loss ÷ 验证集每 token 字节数 ÷ ln2，压缩率按验证集自己计算。

## 结果
| 对照 | 最佳验证 bpb（越低越好） | 结论 |
|---|---|---|
| BPE vs 字符级 | 1.58 vs 1.85 | 字符级的 loss 是 1.29，看上去更低，但每个 token 携带的信息不同；换算成 bpb 后 BPE 更好 |
| 学习率 1e-3 vs 1e-2 | 1.58 vs 1.47 | 原假设"高学习率会不稳定"被推翻：没有出现梯度尖峰，结果反而更好 |
| 0.9M vs 2.9M 参数（4MB 语料） | 1.58 vs 1.46 | 2.9M 的模型从第 1800 步起过拟合：训练 loss 降到 1.04，验证 loss 从 2.54 回升到 2.76 |
| 同一个 2.9M 模型，语料扩大 10 倍 | 1.46 → **1.18** | 不再过拟合，是所有实验里最好的：瓶颈在数据量，不在模型 |
| 模加法：有 / 无权重衰减 | 验证准确率：第 1300 步 ≥ 99% / 最高 75%（第 3400 步）后回落到 54% | 有权重衰减时，训练集满分（第 400 步）后约 900 步才泛化，属于轻度"顿悟"；到 6000 步也回落到 94%，训练后期不稳定 |

## 局限
单个种子。下结论前应再跑 2–3 个种子。
