# 04 · 7B 人格模型为什么会退化：单变量实验

日期 2026-11-16 · Qwen2.5-7B-Instruct（8 位 MLX）+ LoRA，[mlx_lm](https://github.com/ml-explore/mlx-lm) 0.32.2 · 单个随机种子 · 脚本 `scripts/run_7b_variant.py`

## 问题
一个 7B 人格陪伴模型（数据 v8：2,637 条，提示是"整张人设卡 + 好友的话"）训练后答非所问，并把人设卡里的指令词（"接住""顶嘴"）当成台词念出来。同一份数据在 0.6B 上用 TinyLab 的配方训练是正常的（见 [03](03-persona-diagnosis.md)）。问题出在哪里？

## 方法
- 固定数据和其它所有配置，**一次只改一个变量**，每个变量训练 400 步。
- 第 200 步、第 400 步各评估一次，评估集是 v8 验证集里没参与训练的 48 条回答，外加 12 个没见过的问题。
- 生成用温度 0.7、top-p 0.9、重复惩罚 1.1。
- 每个变量都和**同一提示格式下的原始基座**（第 0 步）比较。

| 指标 | 含义 |
|---|---|
| 留出回答损失 | 48 条没见过的参考回答，平均每 token 负对数概率；高于基座 = 被改坏了 |
| 切题度 | 用原始基座给生成的回答打分：配自己的问题 − 配别的问题 |
| 卡词 | 12 条生成里出现"接住""顶嘴"等人设卡指令词的条数 |
| 判型 | 同一条回答放在 16 张卡下，哪张卡概率最高（随机 6.25%；48 条，±13pp 以内看不出差别） |

## 结果（第 400 步；括号里是同格式基座）
| 实验 | 只改了什么 | 留出回答损失 | 切题度 | 卡词 | 判型 | 判定 |
|---|---|---|---|---|---|---|
| V0 | 复现原配方 | 3.92（3.91） | 0.31（1.16） | 4/12 | 15%（21%） | 退化 |
| V5 | 打开 Adam 偏差修正 | 4.20（3.91） | 0.15（1.16） | 5/12 | 27%（21%） | 退化 |
| V1 | 学习率预热 + 余弦衰减 | 4.63（3.91） | 0.05（1.16） | 1/12 | 13%（21%） | 退化 |
| **V3** | **人设卡从用户消息移到 system** | **3.55（3.78）** | **0.85（1.19）** | **0/12** | 17%（25%） | **基本健康** |
| V2 | LoRA 插满全部 28 层 | 进行中 | | | | |
| V4 | bf16 原版基座（不用 8 位） | 进行中 | | | | |

**V0 精确复现了原训练**：前 30 步的训练损失（5.433、5.974、5.127）和原日志逐位一致。第 200 步的留出回答损失（4.10）比训练前还差。

## 一路被推翻的假设
1. **"步长太大"（V5、V1）。**
   - 依据：mlx 的 Adam 默认不做偏差修正。前 100 步的实际步长是设定值的 3–6.5 倍，原日志也恰好在第 20 步冲到最高。
   - 结果：打开修正后，开头那次冲高推迟到第 40–50 步，但没有消失。加学习率预热之后，学习率更小，结果反而更差。
   - 结论：退化不是步子太大造成的。
2. **"人设卡放错了位置"（V3）：成立。**
   - Instruct 模型对 system 和 user 两种消息有不同的预期。人设卡放在 system 里，模型把它当成"我的设定"。
   - 放在用户消息里，模型把它当成"对方说的话"。训练目标又是"顺着这段用户消息回答"，模型就学会了模仿卡里的措辞。
   - 改到 system 后：留出损失从第 200 步起就低于基座，卡词降到 0，切题度保持在基座的 72%。

## 还没解决的
- V3 的判型从 25% 降到 17%，在 48 条的噪声范围内，但方向不好。需要跑满 1 轮、换种子确认。
- 切题度仍然比基座低 28%，说明还有别的因素。V2、V4 的结果出来后再补。
- 单个种子；只训到第 400 步（约 0.3 轮）。

## 对实践的启示
同一份数据，提示格式一变，结果就从"退化"变成"健康"。在 Instruct 模型上做人设微调，人设应该放在 system 里，并且训练和推理用同一个格式。调学习率、调优化器之前，先检查数据的提示格式。
